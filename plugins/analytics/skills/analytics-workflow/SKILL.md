# 分析ワークフロー

具体的な業務目標は依頼に従う。このスキルは、必要な専門スキルを選び、分析の進行を統合する。
analytics-* の Skill を積極的に利用すること。

## 着手

- 関連ドキュメント・既存実装・関連スキル・メモリを参照し、ゼロ探索を避ける。
- 理解した内容と仮定を明示してから着手する。不明点は推測せず質問し、複数解釈では最尤の解釈を明示する。
- サイレントな失敗・スキップは禁止。想定外の状態は握り潰さず記録し、判断を仰ぐ。必要な専門スキル

## 完了時

- 主要結論ごとに、バイアス・因果と相関・見せかけ数値を点検する。
- 分析過程、再実行方法、相関/因果の区別、限界を成果物に残す。
- 指定外のデータソース/ツールを使っていないこと、PII・取引先情報を安全に扱ったことを確認する。
