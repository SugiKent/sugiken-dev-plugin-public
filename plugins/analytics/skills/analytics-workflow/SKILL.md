# 分析ワークフロー

具体的な業務目標は依頼に従う。このスキルは、必要な専門スキルを選び、分析の進行を統合する。

## 専門スキルの呼び分け

| 場面 | 使うスキル |
| --- | --- |
| 現場の違和感・メモから仮説を立てる | analytics-experience-hypothesis |
| 大量取得・並列の分析を進める | analytics-job-orchestration |
| 集計・分類のコードを書く | analytics-reproducibility |
| 結論を検証する（比較・効果・因果） | analytics-analysis-quality |
| 成果物を保存・更新する | analytics-artifact-management |
| 数値を人に報告する（資料・会話の返答とも） | analytics-human-explanation |

## 着手

- 関連ドキュメント・既存実装・関連スキル・メモリを参照し、ゼロ探索を避ける。
- 理解した内容と仮定を明示してから着手する。不明点は推測せず質問し、複数解釈では最尤の解釈を明示する。
- サイレントな失敗・スキップは禁止。想定外の状態は握り潰さず記録し、判断を仰ぐ。

## 数値を報告するとき

- 会話の返答でも資料でも、数値・比率・判定結果を示すときは analytics-human-explanation に従う。
- 数字の隣に、分子・分母・単位・対象範囲（期間・母集団・基準。例: 入社予定ベースか受注売上ベースか）・比較の手法・検証状態（検証済み／未検証とその理由）を書く。

## 完了時

- 主要結論ごとに、バイアス・因果と相関・見せかけ数値を点検する。
- 分析過程、再実行方法、相関/因果の区別、限界を成果物に残す。
- 人間に最終評価や感想、次に繋がる気づきや生まれた仮説がないかを聞き、その結果を HUMAN_JUDGE.md にまとめる
