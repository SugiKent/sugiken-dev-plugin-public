# 再現可能な分析実装

- 集計・統計はPythonスクリプトで実装し、引数や入力を変えれば再走できる形にする。手作業集計に頼らない。
- 乱数を使うならseedを固定する。環境はvenv等に固定し、スクリプト冒頭に実行方法を書く。
- 統計手法は素朴な比率比較で止めず、必要に応じて経験ベイズ縮小（小標本）・ロジスティック回帰や混合モデル（交絡調整）・カイ二乗/残差分析（分布差）・LRT（変数の寄与検定）を使う。p値と併せて効果量（pseudo-R²等）も報告する。

## テキスト分析と分類

- 形態素解析（janome等）+ 正規表現/TF-IDFなどの機械学習的手法を、LLM分析より優先する。
- LLMによる分類は補助に留め、採用する場合も辞書・ルールを残して決定論的ルールに落とし、カバー率を計測する。改修→実行→確認→改修のループで育てる。
- 辞書/正規表現分類はカバー率だけで採用しない。精度（真陽性率）を別に測る。カバー率が高くても精度が低いことがある（例: 通話辞書でカバー率98%・精度20%。単独の汎用語「人」「夫」「他に」が、話題に触れただけを悩み/希望/障壁と誤計上した）。

採用前に必ず次を行う。

1. 意図を示す共起語を必須化する。単独の汎用語を辞書語にしない（例: 「家族」でなく「家族 + 反対/心配」）。
2. 各カテゴリ50件程度を生レコード抽出して目視し、真陽性率を測る。該当とみなす判定基準も明文化し、採用・格下げ・棄却を決める。
3. 章/指標をまたいで同じ語を別ラベルにすると二重計上になる（例: 「家族」を懸念とVOCで重複カウント）。最終集計前に重複を突合し一本化する。
