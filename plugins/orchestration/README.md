# orchestration

OpenSpec の実装・アーカイブと、複数タブによるリポジトリ点検のスキル。

## スキル一覧

* [110-implement-all-openspec-changes](skills/110-implement-all-openspec-changes/SKILL.md): 承認済み change の全実装を統括する。
* [orca-113-archive-completed-changes](skills/orca-113-archive-completed-changes/SKILL.md): 完了 change を Orca で並行アーカイブする。
* [120-overnight-repository-audit](skills/120-overnight-repository-audit/SKILL.md): 7〜8タブで夜間点検し、修正・再発防止・green・origin との合流を進める。週次版は E2E を除く。
* [backend-implementation](skills/backend-implementation/SKILL.md): change のバックエンド実装を担当する。
* [frontend-implementation](skills/frontend-implementation/SKILL.md): change のフロントエンド実装を担当する。
