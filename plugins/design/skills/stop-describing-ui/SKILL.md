# UI の文言

* タブ名、親の見出し、行の値、操作部を一緒に読む。すでに見えている対象名、使い方の実況、何もできない空欄の説明は省く。見出しを消すときも表や操作部の読み上げ名を保つ。
* ボタンには実行する動詞を使い、結果の通知まで呼び方を揃える。表示する文は、選ぶ材料、実行の影響、失敗から戻る方法に絞る。
* 「作成中」と書く前に、利用者が待っている対象を示す。作成予定の版なら、その行の操作部を待機表示にし、利用可能な版は操作できるままにする。処理の開始・完了は読み上げでも判別できるようにする。
