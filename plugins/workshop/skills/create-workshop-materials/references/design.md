# 勉強会資料のデザインガイドライン

ユーザーからブランド、テンプレート、配色、書体の指定がある場合は、その指定を優先する。

## ブランド設定

| 要素 | 指定 |
| --- | --- |
| フォント | Noto Sans JP |
| 本文 | Noto Sans JP Regular、24pt |
| スライドタイトル | Noto Sans JP Bold、36pt |
| セクション見出し | Noto Sans JP Bold、28pt |
| 注釈 | Noto Sans JP Light、16pt |
| 本文色 | `#000000` |
| 白背景以外の見出し | `#FFFFFF` |
| 背景 | `#FFFFFF` |

## カラーパレット

| 用途 | カラーコード | 使用場面 |
| --- | --- | --- |
| プライマリ | `#2563EB` | 見出し背景、強調テキスト |
| アクセント | `#FF5C35` | CTA、重要ポイント |
| テキスト | `#000000` | 本文 |
| 背景 | `#FFFFFF` | スライド背景 |
| サブ背景 | `#F3F4F6` | 表の偶数行、補足セクション |

## 構成ルール

- 1 スライドにつき 1 メッセージに絞る。
- 原則として余白を十分に取り、主題、補助情報、注釈の優先順位を明確にする。
- 強調には青を基本として使い、注意を一点に集めたい箇所だけオレンジを使う。
- 英語を装飾として加えない。日本語の内容が主役になるように組む。
- 図表は結論を読める形に単純化し、情報量が多い表は分割または要約する。
