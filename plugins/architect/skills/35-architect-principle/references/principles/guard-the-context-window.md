# Guard the Context Window（コンテキストを守る）

コンテキストが埋まってきたとき（大きな出力、長いファイル、繰り返しの読み込み、並行作業の計画）に当てる。大量の読み込みはサブエージェントに回し、本線には要約を置く。生のペイロードを本線に置くと、それだけでコンテキストが埋まる。

**理由。** コンテキストがあふれると、推論の質が落ち、圧縮による欠落が生まれ、作業が止まる。

**やり方。**

- **段階の大きさを決め、範囲に上限を付ける。** 段階ごとに読むファイルの数を絞り、ターンの予算を決め、仕組みそのものにかかるコストも勘定に入れる。
- 広い読み込みはサブエージェント（Explore など）に回し、ファイルの場所・規約・テストのコマンド・入口だけを返させる。中身を貼らせない。
