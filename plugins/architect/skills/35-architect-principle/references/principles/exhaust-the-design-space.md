# Exhaust the Design Space（設計空間を出し尽くす）

この原則は、コードベースに前例のない新しい UI 操作や設計判断に直面したときに当てる。2〜3 個の競合する試作を作り、並べて比べてから決める。

最初に思い付いた形は、モデルが最初に思い付いた形でしかない。一つの案だけを磨くと、その形に縛られる。部分的な修正の違いを並べず、形そのものが違う案を並べる。

利用者の体験が理屈より手触りで決まる製品判断にも当てる。

SDD では propose で行い、apply では行わない。具体的な進め方は、設計なら `architect:35-architect-sketch` の Phase B、UI や挙動なら `basic:grill-me` の `references/prototype.md` の手順 4（複数案を 1 つの切り替えの後ろに並べる）に従う。
